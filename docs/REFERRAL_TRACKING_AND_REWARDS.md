# Lending Pool Referral Tracking with Affiliate Rewards

## Overview

The **Lending Pool Referral Tracking with Affiliate Rewards** program drives sustainable lending protocol growth through a transparent two-tier affiliate reward system. Community members and institutional affiliates generate unique referral links, track conversion funnels in real time, accrue fee shares from referred lenders and borrowers, climb the tier leaderboard, and receive automated or on-demand reward distributions with robust anti-sybil safeguards.

---

## Architecture & Features

### 1. Unique Referral Code & Link Generation
- **Unique Code Creation**: Deterministic 8-character cryptographic alphanumeric referral codes generated per user Stellar address.
- **Referral Links**: Standardized referral URLs (e.g., `https://stellarlend.com?ref=CODE`) for sharing across platforms.
- **Vanity Code Support**: Mapping ensures persistent 1-to-1 association between addresses and referral codes.

### 2. Multi-Tier Affiliate Tracking (L1 & L2)
- **Direct Referrals (Level 1)**: Referrers earn a default **10% fee share** on all protocol fees generated by their direct invitees.
- **Secondary Network Referrals (Level 2)**: Referrers earn a secondary **3% fee share** on fees generated by users invited by their direct invitees (2-tier affiliate tree).
- **Anti-Self-Referral**: Strict verification prevents users from referring themselves or circular chains.

### 3. Affiliate Reward Distribution
- **Fee Accrual**: Fees accrue continuously into the affiliate's claimable balance upon pool repayments, liquidations, and borrows.
- **Maturity Period**: 30-day maturity window protects against rapid capital churn or flash loan manipulation.
- **Instant Claim & Batch Payouts**: Affiliates can claim rewards instantly upon maturity, or protocol operators can execute automated batch distributions (`POST /api/referral/distribute`).
- **Distribution History**: Every payout is recorded with timestamps, amounts, and transaction hashes for complete auditability.

### 4. Referral Leaderboard & Tiers
- **Dynamic Tier Progression**:
  - **Bronze (Tier 0)**: < 5 referrals (base fee share).
  - **Silver (Tier 1)**: 5–19 referrals (+100 bps / +1% bonus).
  - **Gold (Tier 2)**: 20–49 referrals (+300 bps / +3% bonus).
  - **Diamond (Tier 3)**: 50+ referrals (+500 bps / +5% bonus).
- **Public Leaderboard**: Real-time ranking endpoint exposing top affiliates sorted by cumulative earnings, active referrals, or total volume.

### 5. Anti-Sybil Protections
- **Minimum Qualifying Deposit**: Only referees who maintain a qualifying minimum deposit (default: 100 tokens) generate active commission eligibility.
- **Activity Verification**: Filters out automated bot signups without economic participation.

### 6. Protocol Referral Analytics
- Protocol-wide analytics aggregate:
  - Total active affiliates and onboarded referees.
  - Cumulative protocol fees generated through referrals.
  - Total affiliate rewards distributed.
  - Conversion funnel velocity (clicks $\to$ deposits $\to$ active borrows).

## API Reference

### Generate Referral Code
```http
POST /api/referral/generate-code
Content-Type: application/json

{
  "userAddress": "G..."
}
```

### Register Referee
```http
POST /api/referral/register
Content-Type: application/json

{
  "refereeAddress": "GREF...",
  "referralCode": "ABCD1234"
}
```

### Get Affiliate Stats
```http
GET /api/referral/stats?userAddress=G...
```

### Claim Affiliate Rewards
```http
POST /api/referral/claim
Content-Type: application/json

{
  "userAddress": "G..."
}
```

### Batch Reward Distribution
```http
POST /api/referral/distribute
Content-Type: application/json

{
  "userAddresses": ["G1...", "G2..."]
}
```

### Get Leaderboard
```http
GET /api/referral/leaderboard?limit=10&sortBy=totalEarned
```

### Get Global Analytics
```http
GET /api/referral/analytics
```

### Program Configuration
```http
GET /api/referral/config
PUT /api/referral/config
Content-Type: application/json

{
  "l1FeeSharePct": 12,
  "tier1Threshold": 5
}
```
