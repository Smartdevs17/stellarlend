# Issue #1192: no code deliverable

Issue #1192 ("Bounty Settlement for 11 Merged Security PRs per SECURITY.md")
was assigned through the Stellar Wave program. It asks the maintainers to
settle bounties manually, in USDC or XLM, for 11 security PRs that had already
merged (#1117, #1118, #1120–#1124, #1137–#1140).

It is a payment request to the maintainers, not a change to the codebase, so a
contributor cannot resolve it with code. Whether and how to settle it is the
maintainers' decision.

For reference, `SECURITY.md` currently says nothing about bounties or manual
settlement.

This note records that the assigned issue was reviewed and found to have no
implementation work. Maintainers can close #1192, or name a concrete
deliverable (for example, documenting a bounty-settlement process in
`SECURITY.md`) for a follow-up PR.
